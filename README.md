# Ashish Pardeshi — Data & BI Portfolio

A polished, responsive personal portfolio for Ashish Pardeshi, positioned for
Data Analyst and Business Intelligence Analyst opportunities.

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser. Create a production build with
`npm run build`.

The main page content is in `app/page.tsx`; the visual system and responsive
layout are in `app/globals.css`.

## Included

- Recruiter-friendly hero and positioning
- About and cross-industry experience
- Six detailed analytics case studies
- Skills, education, resume, and contact sections
- Responsive mobile, tablet, and desktop layouts
- Accessible navigation and reduced-motion support
